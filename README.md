# Interactive Dashboarding & Data Storytelling Project

## Project Overview

This project focuses on Business Intelligence, Interactive Dashboarding, Data Storytelling, and Statistical Validation using coffee shop transaction datasets. The objective of the project was to transform raw transactional data into actionable business insights through analytics, visualization, KPI monitoring, customer segmentation, and hypothesis testing.

The project demonstrates a complete end-to-end analytics workflow, including data preprocessing, exploratory analysis, SQL querying, dashboard development, business storytelling, and statistical validation.

---

# Project Objectives

- Analyze coffee shop sales and customer behavior
- Identify revenue and transaction trends
- Define and monitor key business KPIs
- Build an interactive Power BI dashboard
- Perform customer segmentation analysis
- Validate business insights using statistical testing
- Present findings through business-focused storytelling

## 4. KPI Definition & Dashboarding

### Core KPIs Defined

| KPI | Description |
|---|---|
| Total Revenue | Total sales generated |
| Average Order Value | Average customer transaction value |
| Total Transactions | Total number of purchases |
| Peak Sales Hour | Highest revenue-generating hour |
| Top Selling Product | Most popular coffee product |

An interactive Power BI dashboard was developed to monitor these KPIs dynamically.

---

## 5. Customer Segmentation Analysis

Customers were segmented into:
- High Value Customers
- Medium Value Customers
- Low Value Customers

The segmentation analysis helped identify spending behavior and revenue contribution patterns.

---

## 6. Hypothesis Testing & Statistical Validation

### Business Hypothesis
> High-value customer transactions are significantly different from low-value customer transactions.

### Statistical Method Used
- Independent T-Test using Python (SciPy)

### Result
The statistical analysis identified a significant difference in spending behavior between customer groups (p-value < 0.05).
